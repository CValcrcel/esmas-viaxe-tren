# ESMAS-ES+ · Viaxe en tren

Aplicacións web estáticas para a intervención de etiquetado semántico ESMAS-ES+.

## Ligazóns públicas

- APP 1 — etiquetado individual V0 → V1 → E1 → V2: https://cvalcrcel.github.io/esmas-viaxe-tren/
- APP 2 — integración grupal e mapa V3: https://cvalcrcel.github.io/esmas-viaxe-tren/app2/

## APP 1

- V0 → V1 → E1 → V2
- Responsive: portátil, tableta e móbil
- Funciona integramente no navegador
- Non precisa servidor nin base de datos
- Non envía os datos do alumnado a Internet
- Exporta os ficheiros de traballo localmente en JSON

Versión actual publicada: APP 1 v0.5.0.

## APP 2

- Carga entre 2 e 4 ficheiros V2 do mesmo grupo
- Compara unicamente as cinco balizas autorizadas
- Permite resolver as discrepancias mediante decisión grupal
- Xera o mapa conceptual V3
- Exporta o V3 científico en JSON e o mapa final en HTML autónomo
- Responsive e sen dependencias externas

Versión actual publicada: APP 2 v0.1.2.
